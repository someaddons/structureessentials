# Structure Essentials

[![CurseForge Downloads](https://cf.way2muchnoise.eu/full_832882_downloads.svg)][curseforge] [![Minecraft Versions](https://cf.way2muchnoise.eu/versions/832882.svg)][curseforge] [![Download on CurseForge](https://img.shields.io/badge/Download-CurseForge-F16436?logo=curseforge&logoColor=white)][curseforge]

Structure Essentials is a minecraft mod which provides various utilities for structures from faster locating, distance adjustments and structure overlap prevention to random source crash prevention, debug logging, structure/feature performance recording and more.
## Installation

1. Install the required mod loader.
2. Download the mod from the official CurseForge page.
3. Place the `.jar` file in your `mods` folder.

> This mod is officially distributed only through CurseForge. Downloads from other websites may be outdated, modified, or unsafe.
